# Read Ahead для Chrome и Firefox

Чтение страницы или выделенного текста домашним голосом Qwen. Панель поверх
страницы: пауза, предыдущее/следующее предложение, подсветка и автопрокрутка.
Работает с собственным HTTP-сервером Qwen3-TTS. В этом релизе по умолчанию
задан `http://10.44.0.19:8080` в домашней сети автора. Для другого сервера
нужно поменять адрес в `background.js`, `host_permissions` и CSP
в `manifest.json`; голос — в `background.js`.

[Скачать последнюю версию](https://github.com/farwydi/read-ahead/releases/latest).
Расширение не запускает модель само: нужен работающий совместимый сервер,
например [qwentts.cpp](https://github.com/ServeurpersoCom/qwentts.cpp),
с зарегистрированным голосом `russian`.

Серверная часть находится в [server/](server/README.md): закреплённые исходники,
Ansible-сборка и готовые бинарные архивы в релизах `server-v*`.

## Установка

**Firefox 142+**: скачать
[read-ahead-0.1.0-firefox.xpi](https://github.com/farwydi/read-ahead/releases/download/v0.1.0/read-ahead-0.1.0-firefox.xpi).
Открыть `about:addons` → шестерёнка → «Установить дополнение из файла…»,
выбрать XPI и подтвердить установку. Файл подписан Mozilla; установка
постоянная и сохраняется после перезапуска Firefox. Распространение —
через GitHub (unlisted), без страницы в каталоге Firefox Add-ons.
Обновления устанавливаются вручную новым XPI из релиза.

**Chrome 131+**: скачать `read-ahead-0.1.0.zip` из релиза и распаковать
в постоянную папку. Открыть `chrome://extensions`, включить режим
разработчика, нажать «Загрузить распакованное расширение», выбрать папку
с `manifest.json`. Закрепить Read Ahead на панели браузера.
Расширение не опубликовано в Chrome Web Store.

Чтобы собрать такой же архив из исходников:

```sh
git clone https://github.com/farwydi/read-ahead.git
cd read-ahead
python3 package.py
# dist/read-ahead-0.1.0.zip
```

ZIP из исходников не подписан. Для временной проверки в Firefox открыть
`about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» →
`manifest.json` из распакованной папки; такая установка действует до перезапуска.
Для постоянной установки использовать подписанный XPI из релиза.
Сборщик, npm и Rust для установки не нужны.

## Использование

1. Открыть обычную веб-страницу. Для чтения части текста сначала выделить её.
2. Нажать значок Read Ahead или **Alt+Shift+R**. Есть и пункт контекстного меню.
3. Нажать **Читать**. Без выделения читается основная область `main`/`article`,
   иначе — выделенный текст. Длинные предложения делятся на части до 200 символов.

При фокусе на панели: **пробел** — пауза/продолжить, **←/→** — переход,
**Esc** — остановить и закрыть. Галочка «Следить за текстом» управляет
автопрокруткой; подсветка остаётся включённой. Закрытие панели или переход
на другую страницу прекращают чтение. Начало чтения в другой вкладке
останавливает предыдущую.

Чтобы прочитать другое выделение, закрыть панель, выделить текст и открыть снова.
Служебные страницы браузера, встроенный PDF-просмотрщик и текст внутри iframe
не поддерживаются. Для сложной ленты без семантической разметки лучше выделять
нужный текст вручную. Поля ввода и редактируемые области не читаются.

## Данные и устройство

Текст уходит **только после нажатия «Читать»**, только на домашний Qwen.
Расширение не сохраняет историю, текст или аудио, не использует облако,
аналитику и внешние скрипты. Подключение к домашнему сервису — HTTP, без шифрования.
Firefox честно декларирует передачу `websiteContent` для обработки.

Запросы выполняет фоновая часть с доступом только к хосту Qwen;
`connect-src` дополнительно ограничен портом 8080. Страницы получают
доступ через `activeTab` после явного вызова расширения. Постоянного
разрешения читать все сайты нет.

`POST /v1/audio/speech`: модель `qwen3-tts`, голос `russian`, PCM16 mono
24 kHz, максимум 256 аудиотокенов. Русский/английский выбираются по наличию
кириллицы во фрагменте. Аудио играет через Web Audio. Пауза останавливает
аудиочасы, продолжение идёт с той же позиции.

Сначала загружается целое короткое предложение, затем во время воспроизведения
готовится следующее. Одновременно идёт один запрос; в памяти остаётся не более
трёх соседних клипов. PCM выбран потому, что сервер умеет отменять его генерацию
при разрыве соединения. Таймаут запроса — 25 секунд, ошибки показываются на панели
с кнопкой повтора. Точный адрес и голос заданы в `background.js`; при смене
хоста обновить также `host_permissions` и CSP в `manifest.json`.

Оба браузера используют один Manifest V3: Chrome запускает `service_worker`,
Firefox — `background.scripts` ([MDN](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background)).
Явная CSP нужна в Firefox, чтобы его стандартный `upgrade-insecure-requests`
не заменял домашний HTTP на HTTPS
([MDN](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Content_Security_Policy)).

## Проверка

В исходном репозитории `check.mjs` — один сценарий на настоящих расширениях в отдельных профилях
Chromium и Firefox. Нужны Node.js 22+, Playwright с браузерами, web-ext,
Xvfb и xdotool. Пользовательский профиль не используется, звук проверок выключен.

```sh
node check.mjs              # локальные ответы, включая ошибку и отмену
node check.mjs --live       # дополнительно короткая фраза на настоящем Qwen
node check.mjs --firefox    # только Firefox; есть и --chromium
```

Если модули установлены вне `node_modules`, передать абсолютные каталоги
`READAHEAD_PLAYWRIGHT` и `READAHEAD_WEB_EXT`; `READAHEAD_XDOTOOL` задаёт путь
к бинарю. `PLAYWRIGHT_BROWSERS_PATH` поддерживается самим Playwright.
У Nix-сборки Playwright Firefox дополнительно нужен каталог `libpulseaudio/lib`
в `LD_LIBRARY_PATH`: без него даже обычный Web Audio остаётся с остановленными
аудиочасами. Системный Firefox уже получает эту библиотеку через свою обёртку.

Сценарий проверяет строгий CSP, выделение через вложенные теги, сохранение
пробелов, разбиение текста, подсветку, паузу/продолжение, переходы, HTTP-ошибку
и повтор, отмену запоздавшего ответа и переключение между вкладками.
Скриншоты остаются в игнорируемом `test-results/`, временные профили удаляются.

Проверка манифеста:

```sh
web-ext lint --source-dir . --ignore-files 'dist/**' 'test-results/**' 'server/**' '.gitmodules' 'check.mjs' 'package.py' 'icon.svg'
```

Предупреждение `BACKGROUND_SERVICE_WORKER_IGNORED` ожидаемо: Firefox
использует соседний `background.scripts` из общего манифеста.

2026-09-28 сценарий пройден в Chromium 145.0.7632.6 и Firefox 146.0.1,
включая запрос и окончание воспроизведения настоящего Qwen. Для короткой
фразы «Первое предложение.» старт воспроизведения занял около 1,0 с и 0,9 с
соответственно на уже прогретом сервере. Это проверка транспорта и плеера;
скорость длинных фраз и качество произношения этими числами не оцениваются.
